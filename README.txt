AG Propane CRM — iPhone offline prototype

The CRM stores its live customer data locally on the device/browser using localStorage.
It includes Add Customer, Find/Edit, Follow-Ups, Pipeline, customer history notes, Log Visit/Call, phone calling, and Apple Maps buttons.

Important: local browser storage is device-local. Before relying on it for important business records, use the backup/export version we can add next so you can save a copy to iCloud Drive.
